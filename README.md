# Campus — маркетплейс для студентів

Campus — навчальний вебзастосунок для пошуку, купівлі, продажу та обміну речами між студентами.

## Проблема, мета й аудиторія
Студентам складно швидко знайти доступні вживані речі поруч. Мета — зручний каталог з пошуком за назвою та містом. Аудиторія: студенти університетів України.

## Ролі
- Гість: перегляд оголошень, пошук.
- Користувач: у перспективі публікація та керування власними оголошеннями.
- Модератор: у перспективі перевірка скарг.
- Адміністратор: у перспективі керування ролями та категоріями.

## Сторінки й функції
Заплановано: головна сторінка, каталог оголошень, категорії, пошук, обране, реєстрація, особистий кабінет, панелі модератора та адміністратора.

## Технології
HTML5, CSS3 (Flexbox, Grid, media queries), JavaScript без бібліотек, Git, Trello.
