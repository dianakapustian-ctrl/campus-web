# Trello — картки для створення вручну

Колонки: **Backlog**, **To Do**, **In Progress**, **Review**, **Done**.

Для кожної картки: відповідальний `[ПІБ]`, дедлайн `[вказати реальну дату]`, чекліст, мітка, очікуваний результат та критерій готовності.

| Колонка | Назва | Мітка | Чекліст | Очікуваний результат / критерій готовності |
|---|---|---|---|---|
| Done | Створити технічне завдання | Documentation | Опис; ролі; вимоги | Заповнений technical-requirements.md |
| Done | Розробити головну сторінку | Frontend | Header; hero; footer | Відображається у браузері |
| Done | Створити каталог | Frontend | 4 картки; Grid; адаптивність | 4/2/1 колонки |
| Done | Розробити пошук | Frontend | Поле; місто; JS | Картки фільтруються |
| Review | Перевірити доступність | Testing | Tab; focus; alt | Усі кнопки доступні з клавіатури |
| To Do | Підготувати звіти та скриншоти | Documentation | Звіти; скрини; архів | Матеріали готові до здачі |
| Backlog | Розробити авторизацію | Backend | Форма; API; тест | Реальна авторизація (майбутнє) |
| Backlog | Створити базу оголошень | Database | Схема; CRUD; тест | Дані зберігаються (майбутнє) |
